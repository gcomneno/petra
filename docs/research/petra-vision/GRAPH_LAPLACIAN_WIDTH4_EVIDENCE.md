Created: 2026-08-05

## Status and scope

Status: **bounded reproducible computational research evidence**.

This is an experimental width=`4` extension of the canonical
`petra-vision-graph-laplacian-v1` study. It imports and reuses the frozen v1
graph construction, minimum-component probe, exact Euler update, denominator
`8`, and sample steps `1, 2, 4, 8, 16, 32`. No Laplacian engine is copied or
altered.

Width `4` is outside the Phase 1 runtime contract. The research tool contains
an isolated encoder with the same nested-frame placement recurrence as the
Phase 1 grammar, but intentionally does not call the Phase 1 validator. It is
not a production encoder, decoder, or expansion of the supported runtime
domain.

## Corpus construction

The tool deterministically enumerates the following nested `Terminal` /
`OrderedGroup` domains, all with maximum depth `3` and maximum structural-node
count `7`:

| Set | Maximum width | Forms | Definition |
| --- | ---: | ---: | --- |
| Phase 1 | `3` | `110` | original bounded domain |
| Extended | `4` | `137` | structural extension |
| Held-out | `4` | `27` | extended domain minus Phase 1 domain |

The held-out set is not a genuinely independent external corpus. It is a
structural extension generated by the same grammar and deliberately kept out
of the original Phase 1 design and primary analysis. It is useful as a narrow
boundary check, not as evidence of external generalization.

Every geometry in the extended corpus, including all width=`4` forms, remains
within `181` occupied cells, width `25`, and height `13`. These are observed
and asserted resource bounds for this experiment; they do not change a
production resource contract.

## Results

The reported readers are the v1 null oriented control, global value multiset,
component-separated multiset, and oriented sampled state. Results are exact
integer-numerator comparisons under the frozen protocol.

| Corpus | Reader | Distinct signatures |
| --- | --- | ---: |
| Held-out | null oriented | `27/27` |
| Held-out | global multiset | `27/27` |
| Held-out | component multiset | `27/27` |
| Held-out | oriented | `27/27` |
| Extended | null oriented | `137/137` |
| Extended | global multiset | `136/137` |
| Extended | component multiset | `136/137` |
| Extended | oriented | `137/137` |

There are no new collision shape codes in the extended corpus. The sole
collision for both multiset readers is the preexisting pair:

```text
G(G(G(T)),G(T,T))
G(G(T,T),G(G(T)))
```

The collision remains attributable to the loss of spatial order between
disconnected components under the coordinate-free multiset observations. The
tool identifies this pair by its stable structural shape codes, not merely by
enumeration indices. Oriented results retain cell-order information and must
not be interpreted as coordinate-free dynamic separation.

## Conservative interpretation

The held-out `27/27` result is not proof of universal injectivity, an external
validation result, or a theorem over wider or deeper shapes. It does not
establish a physical propagation mechanism, a dynamic decoder, noise
robustness, security, or a change to Phase 1 acceptance obligations. Further
work still requires independently sourced domains, alternate graph or
boundary constructions, and observation-noise controls.
