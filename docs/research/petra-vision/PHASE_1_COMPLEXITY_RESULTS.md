# PETRA VISION Phase 1 complexity measurement evidence

Schema: `petra.vision.phase1.complexity.v1` (version 1).

## Purpose and timing limitations

This diagnostic records structural and geometry complexity for every bounded Phase 1 shape.

Diagnostic timing only; it establishes no performance threshold, optimality, production-readiness, or cross-machine comparison.

## Environment and methodology

- Python: CPython 3.12.13
- Platform: Linux-6.8.0-136-generic-x86_64-with-glibc2.39
- Timer: time.perf_counter_ns
- Samples: 7; iterations per batch: 100
- Method: one encode/decode roundtrip per shape before measurement; median of the per-batch integer nanoseconds per operation; each raw batch duration is floor-divided by iterations, and loop overhead is not subtracted
