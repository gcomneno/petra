# Historical PET Foundations

This directory contains design and research material created before PETRA became
the sole project architecture.

Its files may explain how object-native grammar, addresses, operators, paths,
metrics, or projections were explored. They are not current specifications.

The valid object-native operator semantics were promoted and consolidated into:

- [`../reference/SPEC.md`](../reference/SPEC.md)

## Classification

All other documents in this directory are one or more of:

- historical PET or PET/PEG design notes;
- superseded executable contracts;
- compatibility analyses;
- research proposals;
- implementation snapshots.

They must not be used to override or extend PETRA semantics.
