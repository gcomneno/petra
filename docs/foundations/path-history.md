# Introduzione

Questo documento introduce il concetto di memoria trasformazionale nel framework PET/PEG.

---

# 1. Path-History

La path-history di un oggetto PET è la traiettoria operatoriale che conduce allo stato corrente.

Essa rappresenta:

- memoria trasformazionale
- ordine operatoriale
- dipendenza dal percorso
- continuità dinamica

---

# 2. Route PET

Una route PET è una sequenza di trasformazioni tra stati PET.

Esempio astratto:

    NEW → INC → REDIRECT → DEC

---

# 3. Path Dependence

Domanda fondamentale:

    L'ordine degli operatori modifica
    il risultato strutturale finale?

---

# 4. Path Equivalence

Due path-history possono essere:

- numericamente equivalenti
- strutturalmente equivalenti
- storicamente differenti

---

# 5. Historical Identity

Ipotesi esplorativa:

    La path-history potrebbe contribuire
    all'identità dell'oggetto PET.

---

# 6. Irreversibilità

Possibile proprietà emergente:

    alcune trasformazioni potrebbero
    distruggere informazione storica.

---

# 7. PEG Dynamics

La path-history collega:

- algebra operatoriale
- connectivity dynamics
- recoverability
- continuity
