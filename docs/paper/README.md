# PET Paper Material

This directory contains paper-oriented material for PET.

## Structure

- `sections/` — draft sections of the paper
- `figures/` — figures used or intended for the paper
- `data/` — paper-side datasets, tables, or derived artifacts used to support figures or claims

## How to read this area

### If you want the paper draft itself
Start in:

- `sections/`

### If you want visual material
Look in:

- `figures/`

### If you want the supporting paper data
Look in:

- `data/`

## Important note

This directory is paper-oriented, not project-wide source of truth.

The paper may contain:
- condensed explanations
- reordered arguments
- selected experiments
- presentation choices optimized for exposition

For project-wide source of truth, see:

- `../VISION.md`
- `../STATUS.md`
- `../PET-METICA.md`
- `../reference/SPEC.md`

## Suggested workflow

A reasonable order is:

1. stabilize ideas in `../PET-METICA.md` or `../research/`
2. move robust results into `sections/`
3. keep figures in `figures/`
4. keep supporting artifacts in `data/`
